syc sync 便携版
================

把西交思源学堂（LMS）的待办、作业说明和截止时间同步到
《Chill With You : Lo-Fi Story》的待办列表和「LMS 作业」笔记页。

一、新电脑上的准备
1. 已安装《Chill With You : Lo-Fi Story》，并启动一次游戏、打开一次「待办」功能
   （这样游戏会生成待办列表存档）。
2. 关闭游戏。
3. 把整个 syc-sync 文件夹放在任意位置。
   注意：要复制整个文件夹，不能只复制 Sync Now.bat。

二、第一次运行
1. 双击 Sync Now.bat。
2. 首次会打开 Edge 登录页，请登录西交统一身份认证（账号密码/动态码/扫码）。
   登录 Cookie 会保存在本文件夹的 browser-profile 里，只留在本机。
3. 看到“已写入待办”“笔记：新增 … 行”就成功了。
4. 打开游戏 → 笔记 → 页面「LMS 作业」，即可看到完整作业内容。

如果打开笔记看到空白页：
- 先点一下笔记列表里的「LMS 作业」；
- 新版会把游戏自动生成的空白「新页面」复用/重命名为「LMS 作业」，并删掉多余空页；
- 旧版留下的空页，关闭游戏后重新运行一次 Sync Now.bat 即可清理。

三、自动同步（可选）
1. 建议先把整个文件夹放到一个固定位置，再双击 Install Auto Sync.bat。
2. 之后登录 Windows 会自动在后台运行；默认每 120 分钟刷新一次 LMS，
   游戏退出后立即把缓存写入存档。
3. 卸载：双击 Uninstall Auto Sync.bat。

四、常见问题
- 提示“没有找到游戏待办列表存档”：先启动游戏，打开一次「待办」再关闭。
- 提示“LMS 登录已失效”：手动运行 Sync Now.bat 重新登录。
- 游戏正在运行：关闭游戏后再同步；自动同步会在游戏退出后补写。
- 自动同步仍觉得有窗口：把 config.json 的 "auto_mode" 改成 "on_exit"，
  重新双击 Install Auto Sync.bat。
- 笔记里删掉某一行后，下次不会自动写回；想恢复见 README.md。
- 本便携版不包含原电脑的登录 Cookie、缓存和备份，所以第一次必须登录。
- 如果 Windows 安全中心/杀毒软件拦截 runtime\python.exe 或 tools\msedgedriver.exe，
  请选择“允许”/“仍要运行”。msedgedriver 是微软官方的 Edge 驱动。

详细说明见 README.md。
